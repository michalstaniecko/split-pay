# GitHub Sponsors link only on the web and in the README

The project is free and supported through GitHub Sponsors, but the support link appears only in the web interface and the README, never as a clickable link in the mobile app. Apple (guideline 3.1.1) and Google Play penalise links to external payments and developer tips, and a rejection in review is not worth that risk. AdMob may be added later, behind a feature flag.
