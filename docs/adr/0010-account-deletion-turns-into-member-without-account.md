# Deleting an account turns the user into a member without an account

Deleting an account (an Apple requirement) does not delete expenses or shares, because that would break the other members' balances. Personal data is removed, and in every group an ordinary member without an account named "Deleted user" remains. Any group member can rename it, and it can be claimed like any other member without an account.

_Amended by [ADR-0019](./0019-account-deletion-keeps-name-by-default.md): by default the member keeps its last name; "Deleted user" applies only when the user chooses to remove their name too._
