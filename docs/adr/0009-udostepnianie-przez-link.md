# Udostępnianie przez link i systemowy arkusz, bez wysyłki z serwera

Zapraszanie i udostępnianie odbywa się przez sekretny, unieważnialny link grupy (universal link / app link), wysyłany przez systemowy arkusz udostępniania, oraz przez kod QR. Serwer nie wysyła maili ani SMS-ów z zaproszeniami: to koszty, problemy z dostarczalnością i spamem, a użytkownicy i tak wolą wkleić link na grupowy czat. Link bez zainstalowanej aplikacji otwiera podgląd www (bez zdjęć i bez edycji).
