# Jedno źródło kursów walut (ECB) i kurs zamrażany przy wydatku

Kursy pochodzą wyłącznie z ECB (przez Frankfurter) i są pobierane przez serwer raz dziennie. Kurs jest zamrażany w wydatku w chwili dodania i można go edytować ręcznie. Mimo polskich użytkowników nie używamy NBP: dwa źródła to dwa razy więcej kodu, a różnica w dokładności nie ma znaczenia przy rozliczeniu ze znajomymi.
