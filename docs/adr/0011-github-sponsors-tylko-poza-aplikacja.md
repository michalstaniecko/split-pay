# Link do GitHub Sponsors tylko w www i README

Projekt jest darmowy i wspierany przez GitHub Sponsors, ale link do wsparcia pojawia się tylko w interfejsie www i README, nigdy jako klikalny link w aplikacji mobilnej. Apple (wytyczne 3.1.1) i Google Play karzą za linki do zewnętrznych płatności i napiwków dla dewelopera, a odrzucenie w review nie jest warte tego ryzyka. AdMob może dojść później, za feature flagą.
