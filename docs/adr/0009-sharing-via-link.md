# Sharing via link and the system share sheet, no sending from the server

Inviting and sharing happen through a secret, revocable group link (universal link / app link), sent via the system share sheet, and through a QR code. The server does not send invitation emails or text messages: that means costs, deliverability problems and spam, and users prefer to paste a link into the group chat anyway. Without the app installed, the link opens the group preview (no photos and no editing).
