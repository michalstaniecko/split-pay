# No roles in a group, full change history

Every group member can edit and delete any expense, income and settlement, and rename members without an account. The safeguard is not permissions but a change history with the ability to undo. The only exception: only the owner can permanently delete a group. Roles would get in the way, especially when someone enters expenses on behalf of a member without an account. Requests for "owner-only permissions" are the first step towards a role system that we deliberately rejected.
